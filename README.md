# Darshan Goneppanavar Portfolio

Built with React, Vite and GSAP. 
All site content is in `src/data.js`.

## Run locally
```bash
npm install
npm run dev
```

## Assets
Everything the site loads is in `public/`:

- `hero/` hero video and poster
- `profile/` badge portrait
- `resume/` resume download and preview image
- `certs/` certificate PDFs, previews and badges
- `scene/` skills section scene images
- `favicon.svg` and `og.png` at the root
